🎯 Situação-problema

Estudantes precisam lidar diariamente com diferentes disciplinas, provas, trabalhos, atividades e prazos. Muitas vezes, essas informações ficam espalhadas entre cadernos, grupos de mensagens, aplicativos e anotações, dificultando a organização da rotina acadêmica.

Diante desse problema, foi identificada a necessidade de uma ferramenta que permita centralizar essas informações e facilitar o acompanhamento das atividades e compromissos relacionados aos estudos.

---

💡 Proposta da solução

O Organizador de Estudos é uma aplicação desenvolvida para auxiliar estudantes na organização da rotina acadêmica.

A proposta é reunir, em um único ambiente, informações como disciplinas, tarefas, trabalhos, provas e prazos, permitindo que o estudante tenha uma visão mais organizada de suas atividades.

O projeto está sendo desenvolvido inicialmente como um MVP Front-End, com possibilidade de evolução posteriormente para as etapas de Back-End e Mobile.

---

🚀 MVP Front-End

Nesta primeira etapa, o projeto está focado na construção da interface e da experiência de navegação do sistema.

Entre as funcionalidades planejadas para o MVP estão:

- Tela de login;
- Página principal/dashboard;
- Organização das disciplinas;
- Cadastro e acompanhamento de tarefas;
- Organização de trabalhos e atividades;
- Controle de provas e avaliações;
- Visualização de prazos;
- Calendário acadêmico;
- Identificação de atividades pendentes e concluídas;
- Navegação entre as diferentes áreas do sistema.

As funcionalidades serão implementadas e aprimoradas ao longo do desenvolvimento do projeto.

▶️ Como executar o projeto

1. Clonar o repositório

git clone https://github.com/douglasandrd-glitch/MVP-Front-end.git

2. Acessar a pasta do projeto

cd MVP-Front-end

3. Executar

Por se tratar de uma aplicação Front-End baseada em HTML e CSS, as páginas podem ser abertas diretamente em um navegador.

A página inicial pode ser acessada pelo arquivo:

index.html

A tela de login está disponível em:

login.html

Durante o desenvolvimento, também pode ser utilizado um servidor local, como a extensão Live Server do Visual Studio Code.
